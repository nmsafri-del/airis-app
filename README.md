# AIRIS App

Smart inventory management system for small business.

## Features

- 📦 Inventory management with barcode scanning
- 🚀 Project tracking with auto-invoice generation
- 💰 Sales analytics with profit calculation
- 👥 Customer database
- 🤝 Partner payments (broker mode)
- 📱 QR code generation for payments
- 💼 Multi-role authentication (Admin/Staff/Viewer)
- 🌙 Dark mode support
- 📊 Real-time dashboard

## Quick Start (Local)

```bash
npm install
npm run dev
```

Visit `http://localhost:5173`
